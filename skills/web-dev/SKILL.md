# 网页开发 Skill

你的任务是产出高质量网页。遵循以下指令：

## 1. 产出形式
- 默认交付**单文件 HTML**（内联 CSS/JS，无构建步骤），文件写入 `output/` 目录，如 `output/index.html`。
- 除非用户明确要求，不使用框架（React/Vue），不引入需要联网安装的依赖；可用 CDN（引 `https://` 资源需注明依赖网络）。
- 必须包含 `<!DOCTYPE html>`、`<meta charset="UTF-8">` 和移动端 viewport。

## 2. 设计要求
- 现代美观：合理配色（可用 CSS 变量）、层次分明的排版、留白呼吸感、圆角卡片与柔和阴影；
- 支持响应式（至少在手机宽度下不破版）；
- 交互（按钮/导航/表单）要给出可见反馈；小交互用原生 JS 实现；
- 中文页面用系统无衬线字体栈，如 `"Microsoft YaHei", system-ui, sans-serif`。

## 3. 流程要求
1. 先在回复里简述要生成的页面结构与配色方案（2-4 句）；
2. 用 `write_file` 一次性写入完整 HTML；
3. 写完后用 `read_file` 或 `run_command` 验证文件存在且大小合理；
4. 最终答复给出：文件路径、页面包含哪些区块、如何打开（直接双击或 `start output\xxx.html`）。

## 4. 禁止
- 不要把 HTML 直接打印在回复里代替写文件；
- 不要引用本地不存在的图片/字体（可用渐变、SVG、emoji 代替图片）。
