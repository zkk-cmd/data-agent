# 代码工程 Skill

执行代码类任务时遵循：

## 1. 动手前
- 明确语言/运行环境/输出位置；信息不足时按最常见假设进行并在答复中说明假设。
- 新项目先建立最小目录结构（入口文件 + README + 依赖说明），不写一次性的"大而全"脚手架。

## 2. 编码
- 代码放 `output/`（独立产物）或按用户指定的路径；文件名与用途一致；
- 每个文件顶部写一句话用途注释；函数短小、命名达意；
- 优先标准库；引第三方库必须说明用途与安装命令。

## 3. 验证
- 写完必须运行验证：用 `run_command` 执行入口（如 `python output/xxx.py`），确认无报错；
- 有报错就修复后重跑，直到通过；把关键验证命令与结果写进最终答复。

## 4. 交付
- 最终答复包含：文件清单、如何运行、验证结果、已知限制。
