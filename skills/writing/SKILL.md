# 技术文档 Skill

## 1. 先读代码再动笔
- 用 `list_dir` + `read_file` 了解项目结构与真实实现；
- 文档里的 API/参数/示例必须与代码一致，**不编造不存在的接口**。

## 2. 结构（默认模板）
简介（一句话价值） → 安装与依赖 → 快速开始（可运行的最小示例） → API/配置说明 → 常见问题。

## 3. 成稿要求
- 示例代码要么摘自真实代码，要么经 `run_command` 验证可运行；
- 语言简洁，多用列表与代码块；避免营销腔；
- 长文档（>1500 字）用 `write_file` 写入 `output/`（Markdown），回复只给摘要。

## 4. 交付
回复给出：文件路径、文档结构、建议补充的内容。
